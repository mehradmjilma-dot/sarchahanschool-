راهنمای ساخت فایل نصب (Setup.exe) برنامه «مدیریت هوشمند مدرسه سرچهان»
==========================================================================

نتیجه‌ی کار یک فایل SarchahanSchool_Setup.exe است که بدون اینترنت روی هر
ویندوز ۶۴ بیتی (ویندوز ۷ به بالا) نصب می‌شود. سرور و برنامه یکی شده‌اند و
روی هر سیستم فقط همین یک برنامه لازم است.

بخش ۱) ساخت فایل نصب  (فقط یک بار، روی یک سیستم دارای اینترنت)
-----------------------------------------------------------------
پیش‌نیازها:
  • Python 3.8 (نسخه ۶۴ بیتی). همان که الان دارید کافی است.
    موقع نصب پایتون تیک «Add Python to PATH» زده شده باشد.
  • برنامه‌ی Inno Setup 6  (رایگان، از سایت jrsoftware.org).
    اگر نسخه‌ی جدید روی ویندوز ۷ باز نشد، نسخه‌ی قدیمی‌تر 6.x را نصب کنید.

نکته: فایل نصب را روی «قدیمی‌ترین ویندوزی که می‌خواهید پشتیبانی کنید»
بسازید. اگر روی ویندوز ۷ می‌سازید، روی ویندوزهای جدیدتر هم کار می‌کند.

مراحل:
  ۱. کل این پوشه را روی سیستم بسازنده کپی کنید (مثلاً C:\SarchahanSchool_build).
  ۲. (اختیاری) برای آیکون برنامه، فایلی به نام app.ico کنار build_exe.bat بگذارید.
  ۳. اول برنامه را بدون ساخت exe تست کنید:   python school_app.py
     اگر صفحه ورود آمد، همه‌چیز سالم است. (نیاز به: pip install fastapi uvicorn)
  ۴. روی build_exe.bat دوبار کلیک کنید و صبر کنید تا بنویسد DONE.
     (چند دقیقه طول می‌کشد و برای نصب ابزارها به اینترنت نیاز دارد.)
  ۵. برنامه‌ی ساخته‌شده را تست کنید:
         dist\SarchahanSchool\SarchahanSchool.exe
  ۶. فایل installer.iss را با Inno Setup باز کنید و کلید F9 (Compile) را بزنید.
  ۷. فایل نهایی اینجاست:   installer_output\SarchahanSchool_Setup.exe

بخش ۲) نصب روی هر سیستم (بدون اینترنت)
---------------------------------------
  ۱. فایل SarchahanSchool_Setup.exe را با فلش به سیستم مقصد ببرید.
  ۲. اجرا کنید و Next بزنید (نیاز به دسترسی Administrator دارد).
  ۳. بار اول که برنامه باز شود، از شما یک رمز برای حساب مدیر می‌پرسد
     (نام کاربری: admin). حداقل ۸ نویسه.
  ۴. بعد از آن با همین نام کاربری و رمز وارد شوید.

نکته‌های مهم
------------
  • محل ذخیره‌ی اطلاعات:  C:\ProgramData\SarchahanSchool\school.db
    از همین فایل پشتیبان بگیرید. حذف (Uninstall) برنامه آن را پاک نمی‌کند.
  • هر سیستم دیتابیس جدا و مستقل دارد. اطلاعات بین کامپیوترها خودکار
    همگام نمی‌شود. برای انتقال اطلاعات، فایل school.db را کپی کنید
    (برنامه بسته باشد).
  • اگر رمز مدیر را فراموش کردید، هنگام نصب گزینه‌ی «reset admin password
    shortcut» را بزنید تا میانبر بازنشانی رمز در منوی Start ساخته شود.
    توجه: هر کسی که به همان ویندوز دسترسی دارد می‌تواند از آن استفاده کند؛
    در سیستم‌هایی که دانش‌آموزان دسترسی دارند آن را نصب نکنید و حساب
    ویندوز را هم رمزدار کنید.
  • ممکن است آنتی‌ویروس یا SmartScreen برای فایل‌های ساخته‌شده با PyInstaller
    هشدار بدهد، چون فایل امضای دیجیتال ندارد. این هشدار معمولاً اشتباه است؛
    در صورت نیاز فایل را در آنتی‌ویروس مجاز (Exclude) کنید.
  • فقط ویندوز ۶۴ بیتی پشتیبانی می‌شود (چون پایتون ۶۴ بیتی است).
